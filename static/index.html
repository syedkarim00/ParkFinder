Ontario Parks availability helper

Capture a real Ontario Parks browser search.

ParkFinder now uses Playwright as the only thing that accesses Ontario Parks. It launches headed Chromium, lets you complete a normal search, and saves the browser's JSON responses, page text, and screenshot.

Open official reservation site

Run the recorder

Run these commands in your terminal. When Chromium opens, complete the Ontario Parks search manually. Then return to the terminal and press Enter to save the captured results.

python3 -m pip install -r requirements.txt
python3 -m playwright install chromium
python3 -m parkfinder.playwright_recorder

The recorder writes captured-responses.json, results-text.txt, results.png, and browser-state.json.

Replay your codegen flow

The Algonquin - Kiosk / June 5-7 / Single Tent selectors you recorded can be replayed with:

python3 -m parkfinder.playwright_recorder \
  --use-codegen-flow \
  --park "Algonquin - Kiosk" \
  --arrival 2026-06-05 \
  --departure 2026-06-07 \
  --equipment "Single Tent" \
  --click-resource -2147474195 \
  --click-resource -2147474194

If it is flaky, slow it down with --step-pause-ms 1500 --settle-ms 4000. To repeat weekends, add --weekend-count 3; to repeat parks, add one or more --extra-park "Park Name" flags.

No direct Python scraping

This version does not call hidden Ontario Parks API URLs from Python HTTP clients. The Python code only listens to responses received by the Playwright-controlled browser via page.on("response").

If you see net::ERR_CONNECTION_REFUSED

The local UI server is not running or you opened this file directly. Run python3 -m parkfinder.server, keep that terminal open, and browse to http://127.0.0.1:8000.
