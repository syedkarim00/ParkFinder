Ontario Parks availability helper

Scan every park for every summer weekend.

ParkFinder scrapes the Ontario Parks reservation map tree, checks each complete Friday-to-Sunday weekend in June, July, August, and September, then lists the available campsites with a waterfront/near-water score.

Open official reservation site
What should ParkFinder scan?

The all-parks scan uses the reservation system's root map and follows its region → park → campground links automatically, so you do not need to search each park manually.

Can this run from GitHub Pages?

A GitHub Pages-only site cannot directly scrape the Ontario Parks API because it has no backend and browser CORS rules can block cross-origin API reads. This app is still web-based, but the scraper runs locally in Python; you open the local website at http://127.0.0.1:8000.
